## 一、8 节课课程主线（故事总纲）

### 1.1 世界观（开场第一屏语音）

> 星海深处，有座星光镇。
> 镇上孩子，成年礼是：领一只伙伴。
> 伙伴不是宠物，是星灵。
> 星灵住在小小机器里。会说话，有脾气，有本领。
> 一夜，灰雾来了。
> 灰雾吞掉了星语号。
> 船上锁着八颗星核。
> 星核是星灵的心脏备份。
> 灰雾偷声音，偷记忆，偷本领。
> 驯养员，该你上场了。

孩子身份：**星光驯养员（实习）**。驾小艇登岛，逐关营救、集齐 8 颗星核，最终打开星语号舱门。

### 1.2 伙伴（Agent，开课六选一，贯穿 8 课）

| 伙伴 | 性格 | 口头禅 | 预览区常驻反应 |
|---|---|---|---|
| 傲娇猫·铃铛 | 嘴硬心软 | 「才、才不是！」 | 被夸时扭头，耳朵却竖着 |
| 捧场狗·来福 | 全场最捧 | 「好棒好棒！」 | 别人作品运行时鼓掌 |
| 害羞兔·雪球 | 声音小小 | 「……我在。」 | 长时间没操作会打瞌睡 |
| 话痨鹦鹉·彩虹 | 说不完 | 「然后然后！」 | 通关后复述孩子操作过程 |
| 慢性子龟·阿慢 | 一字一顿 | 「别急……」 | 加载时先伸头再出壳 |
| 博士猫头鹰·咕咕 | 爱讲知识 | 「听我说！」 | 喂错资料时扶眼镜叹气 |

**Agent 角色化铁律**：伙伴是"被营救者+同学"，不是工具。每课学新能力，预览区有对应成长动画（L3 记忆恢复→眼睛亮起；L5 装技能→尾巴竖起/羽毛立起）。剧情推进靠伙伴的失忆与恢复——**教具即角色**。

### 1.3 章节结构（星空闯关地图）

- **第 1 章·回声岛（L1–L4）**：找回伙伴的声音与记忆。岛色暖橙。
- **第 2 章·彩虹环带（L5–L8）**：找回伙伴的本领。岛色七彩。
- 关卡状态机（开发配置项）：`灰锁 → 呼吸发光（可进入）→ 三星彩旗（完成）`。通关一章，全岛点亮一次"环岛烟花"。

### 1.4 悬念递进（每课收尾 15 秒钩子，Ozaria 式追剧结构）

| 课次 | 结尾钩子（旁白+画面） |
|---|---|
| L1 | 灰雾深处，传来一声猫叫。可岛上，没有猫。 |
| L2 | 沙滩上出现脚印。圆圆的。不是动物的。 |
| L3 | 百宝箱底，多出一页记忆。不是我们喂的。上面写着：**灰雾会学人说话**。 |
| L4 | 那页记忆有落款。被水泡花了。只剩一个字：**回**。 |
| L5 | 新技能牌背面，有抓痕。抓痕是新的。 |
| L6 | 我们喊暗号。灰雾那头，回了同一句。 |
| L7 | 烟花夜。天上映出一张脸。脸在笑。 |
| L8 | 舱门开了。里面还有一个笼子。名牌上写着：**第二个伙伴**。灰雾，原来也是星灵。（引出第 3 章） |

## 二、通用机制规格（开发对接基线）

### 2.1 关卡三段式与影子褪除

每关结构：**15 秒过场 → 影子引导创作 → 影子褪除（逐关递减）**。

影子形态四档：

| 档位 | 形态 | 配置 |
|---|---|---|
| S3 全影子 | 半透明实体积木已躺在正确位置，点按即吸附生效 | L1–L2 |
| S2 轮廓 | 虚线框+积木类型图标，孩子需自己从卡包选对类型放入（同类磁吸） | L3–L4 |
| S1 提示词 | 无任何块。仅一行语音+浮动文字提示（如「先放角色卡哦」） | L5–L6 |
| S0 空白 | 只有图鉴可查，无任何引导 | L7（任务清单模式）→ L8（完全自由） |

**缺口** = 影子中留给孩子的空位。**磁吸果冻手感**：正确块靠近正确槽 40px 内吸附，吸附时弹性缩放 1.1→1.0 + 果冻音效。

### 2.2 AI 小精灵三级提示（每关 3 次，永不代拼）

- 一级·指方向：「看看积木区哦」+ 发光箭头。
- 二级·指积木：卡包里正确的卡跳动 +「试试这张卡」。
- 三级·指位置：目标槽位呼吸发光 + 语音读出动作（「把它拖进空槽」），**仍不代拼**。
- 3 次用完：伙伴向孩子"卖萌求助"，任务自动降级为二选一（点选即过，星数上限降为 ★★）。

### 2.3 三星与"点亮知识卡"闭环（自动检测）

- ★ **通关**：完成本关作品并运行成功。
- ★★ **专项检测**：本关核心概念的行为事件达标（事件埋点见各课细案）。
- ★★★ **口诀测验**：小精灵语音三选一（图标选项，零文字依赖），答对。
- **点亮规则**：通关抽到知识卡=灰面卡；★★ 达标 **或** ★★★ 答对 → 点亮（全亮+闪光音效）。图鉴页可见"已抽到/已点亮"两态，制造收集欲。

### 2.4 全局低年级基线

积木文案≤6字；所有旁白/提示双语（语音优先）；无声机房默认视觉模式：错误不用弹窗，用"颜色变灰+轻震动+伙伴歪头"表达；文字输入一律提供录音钮或图标选择替代。

## 三、每课细案 ×8

---

### 第 1 课 · 关卡 1「唤醒伙伴」

**知识点与教学目标**
- 概念：Agent 是"有性格的对话体"；**角色卡（Persona）** 决定"它是谁"。
- 目标：孩子能说出「角色卡改变说话的样子」；独立完成换卡；**开课 10 分钟内得到会回应的伙伴**（硬指标）。
- 本课只做一件事：换角色卡 → 看 AI 回答变样。一步不多。

**15 秒过场脚本**
- 0–5s：黑屏，海浪声。旁白：「灰雾来了。声音，被偷走了。」画面：星空岛轮廓，灰雾压下，岛上音符图标逐个熄灭。
- 5–10s：「伙伴躺在沙滩。它忘了自己是谁。」画面：所选动物蜷成一团，灰色，头顶大问号。
- 10–15s：「驯养员，用一张卡，唤醒它。」画面：一张发光卡片飘到伙伴面前，伙伴耳朵动了一下。「点开始。就现在。」

**新积木图鉴卡：角色卡**
- 卡名：**角色卡 · 它是谁**
- 卡面描述：决定伙伴的性格和说话方式。卡面画：动物证件照+三个性格词条。
- 卡背口诀：**「换张卡，变个它」**

**影子引导方案**
- 作品「沉睡的伙伴」共 4 块：①触发器·点一点（影子）②说话气泡（影子）③开场白「你是谁？」（影子）④**角色卡槽（唯一缺口）**。
- 影子：S3 全影子。缺口数：**1**。
- 第一缺口一步必对：**是**。槽位只接受角色卡类；卡包仅 3 张（傲娇猫/捧场狗/害羞兔）；任意一张都触发唤醒动画。本关失败不可能发生。

**哇哦时刻**
唤醒瞬间：伙伴从灰变彩色、睁眼、第一次用性格口吻自我介绍（傲娇猫：「才、才不是在等你！」），全屏彩带。之后自由换卡：同一个问题「你是谁？」，三种伙伴三种回答，孩子第一次直观看见 Persona。

**三星通关验收（自动检测）**
- ★：`EVT_PERSONA_SWAP ≥1` 且 `EVT_TRIGGER_TAP ≥1`
- ★★：换卡 ≥2 次，且「你是谁」的回答文本随卡片变化（回答差异比对）→ 验证"卡变→答变"理解
- ★★★口诀测验：「想让伙伴变个样，用什么？」选项图标：角色卡/百宝箱/烟花。答对点亮「角色卡」知识卡。

**低年级适配**
卡包仅 3 张（减少选择负担）；操作提示为发光箭头+语音；一年级建议两人一机结对。

**时间分配（45min）**
过场+演示 3′ / 创作 22′（其中 0–3′ 完成换卡出作品，3–10′ 自由换卡比较，10 分钟硬指标达成点）/ 测试问答 8′ / 展示「谁家伙伴最傲娇」10′ / 收尾悬念+图鉴讲解 2′。

### 第 2 课 · 关卡 2「它开口了」

**知识点与教学目标**
- 概念：**触发器**初见（点一点=开关）；角色卡深挖：口头禅、开场白。
- 目标：理解「触发器让伙伴开始行动」；能修改口头禅，看到性格渗进每次回答。

**15 秒过场脚本**
- 0–5s：「伙伴醒了。可它只会一句。像复读机。」画面：伙伴机械重复同一句，头顶循环箭头。
- 5–10s：「驯养员，教它说新话。」画面：一张对话卡飘来，伙伴眼睛发亮。
- 10–15s：「先定暗号：点一点，它就开口。」画面：手指点击图标，一盏灯亮起。

**新积木图鉴卡 ×2**
- 卡名：**触发器 · 点一点**｜卡面：让伙伴开始行动的开关｜口诀：**「点一点，就说话」**
- 卡名：**口头禅 · 挂嘴边**｜卡面：伙伴最爱的那句话｜口诀：**「口头禅，挂嘴边」**

**影子引导方案**
- 作品「爱打招呼的伙伴」5 块：触发器（影子）→角色卡（影子，可自选换）→气泡（影子）→**口头禅字段（缺口1）**→**开场白字段（缺口2）**。
- 影子：S3 全影子。缺口：2，均为自由填空（录音/语音输入/预设图标三选一），**结构上不可能填错**。
- 第一缺口一步必对：**是**（自由内容型缺口）。

**哇哦时刻**
伙伴用**孩子自己录的声音/自己编的口头禅**说话。全班同时点伙伴，教室变成"口头禅大合唱"。另加"它有反应"彩蛋：预览区伙伴被点后会眨眼、跳一下——它是活的。

**三星通关验收**
- ★：`EVT_TRIGGER_TAP ≥3`
- ★★：口头禅文本出现在 ≥2 次回答中（文本匹配）+ 自主换角色卡 1 次
- ★★★口诀测验：「伙伴怎么开始说话？」答「点一点」→点亮「触发器」卡。

**低年级适配**
口头禅从 6 个预设图标中选（如星星/棒棒糖/火箭），或按录音钮说一句；触发器点击热区放大 150%。

**时间分配**
过场 4′ / 创作 22′ / 测试 8′ / 展示 9′ / 悬念收尾 2′。

### 第 3 课 · 关卡 3「喂它记忆」（百宝箱登场）

**知识点与教学目标**
- 概念：**RAG 初见**。AI 不知道的事，喂它；回答亮「用了百宝箱」徽章。
- 目标：区分「它瞎猜」与「它查了资料」；理解顺序：先喂，再问。

**15 秒过场脚本**
- 0–5s：「伙伴想家了。它忘了家。」画面：伙伴仰望星空，头顶一朵空白云。
- 5–10s：「驯养员有百宝箱。里面装知识。喂一口，它想起一口。」画面：宝箱打开，一张卡片飞向伙伴。
- 10–15s：「先喂，再问。记住顺序。」画面：喂食动画→问号→徽章亮起闪光。

**新积木图鉴卡：知识百宝箱**
- 卡名：**百宝箱 · 喂知识**
- 卡面描述：不知道的事，喂给它。卡面画：开口的宝箱，卡片飞入。
- 卡背口诀：**「喂资料，答得妙」**

**影子引导方案**
- 作品「回声岛导览员」：伙伴+触发器（影子，已熟练）+ **百宝箱（缺口1，S2 轮廓）** + 资料卡×3（岛的位置/岛的特产/岛的歌，缺口2 喂入）+ 提问气泡（影子）。
- **影子档位切换：S3 → S2 轮廓**。孩子第一次要自己从卡包拖出正确类型的积木放进虚线框（同类磁吸，异类弹回+小精灵一级提示）。
- 缺口：2。第一缺口一步必对：**基本是**——本关卡包只有百宝箱一种新积木；资料卡喂错位置会被磁吸纠正到箱内。

**哇哦时刻（本课核心，开发必做）**
体验序列强制编排：先问「回声岛在哪？」→ 伙伴答「呃……不知道」+歪头（**先看见无知**）→ 喂资料 → 再问 → 答对 + 右下角**「用了百宝箱」徽章**旋转亮起（金币音效）。孩子的尖叫点：「它不是猜的！它查了我喂的书！」

**三星通关验收**
- ★：作品含百宝箱 + 提问成功 1 次
- ★★：`EVT_BADGE_RAG ≥3`（3 张资料各问 1 次全中）
- ★★★口诀测验：「伙伴怎么知道岛的歌？」选项：喂了资料/它瞎猜/它做梦→点亮「百宝箱」卡。

**低年级适配**
资料卡用图片卡（风景图+语音朗读内容）；"不知道"状态用打哈欠动画表达（视觉模式无文字）。

**时间分配**
过场 5′ / 创作 20′ / 测试（含"先问后喂再问"对比实验）10′ / 展示 8′ / 悬念收尾 2′。

### 第 4 课 · 关卡 4「专属记忆」

**知识点与教学目标**
- 概念：**RAG 深化**——资料质量决定回答质量；专属资料 vs 无关资料。
- 目标：会挑资料；初步建立「AI 的回答来自你喂的东西」的责任意识。

**15 秒过场脚本**
- 0–5s：「坏消息。伙伴连名字都忘了。」画面：问它「你是谁」，它头顶三个问号，眼角有泪光。
- 5–10s：「普通资料，救不了它。要喂它的专属记忆页。」画面：一本相册翻开，泛着金光。
- 10–15s：「别喂错。错了，它会更糊涂。」画面：一张错误卡片被风吹走。

**新积木图鉴卡：专属记忆页**
- 卡名：**记忆页 · 只属于它**
- 卡面描述：喂对资料，它才想得起自己。
- 卡背口诀：**「喂什么，答什么」**

**影子引导方案**
- 作品「找回伙伴的名字」：卡包混放 6 张资料——3 张专属（出生纸/名字的故事/最爱的歌）+3 张干扰（别岛地图/无关笑话/过期新闻）。
- 缺口：3（①建记忆页 ②挑专属资料喂入 ③问「你叫什么」验证）。
- **第一缺口一步必对：否——这是 8 课时中第一个"允许出错"的缺口（设计转折点）**。喂了干扰资料再问名字，伙伴会答非所问（捧场狗：「好棒的问题！但是……我是谁来着？」+歪头）。错误反馈温柔且有戏，然后小精灵三级提示依次介入。

**哇哦时刻**
喂对出生纸的瞬间：伙伴想起自己的名字，原地转圈，头顶小烟花，大喊「我叫来福！！」——记忆恢复动画与 Agent 性格绑定（傲娇猫版本：「……才不是高兴呢。」同时尾巴翘到天上）。收尾钩子：百宝箱底摸出神秘记忆页。

**三星通关验收**
- ★：名字问题回答正确
- ★★：3 个专属问题（名字/最爱/名字的故事）全答对，徽章亮 3 次（`EVT_RAG_HIT_SPECIFIC=3`），且正确回答未被干扰资料污染
- ★★★口诀测验：「想让伙伴答得准，要喂？」答「对的知识」→点亮「记忆页」卡。

**低年级适配**
干扰资料用颜色明显化（专属卡金边、干扰卡灰边），降低甄别负担；高年级保持混合。

**时间分配**
过场 5′ / 创作（含试错）22′ / 测试 8′ / 展示 8′ / 悬念收尾 2′。

### 第 5 课 · 关卡 5「它有本领了」（技能登场）

**知识点与教学目标**
- 概念：**Tool Calling**——装技能，Agent 自主选；孩子只说事，不指定工具。
- 目标：说出「技能是它自己选的」；观察举牌行为与指令的对应。

**15 秒过场脚本**
- 0–5s：「彩虹环带。七座桥。桥断了，没人修。」画面：彩虹断成七截，垂进海里。
- 5–10s：「伙伴不会修桥。它没有本领。给它技能牌。」画面：两张发光技能牌飞来。
- 10–15s：「记住：牌装上，它自己举。你说事，它来选。」画面：伙伴接过技能牌，插在背后。

**新积木图鉴卡：技能牌**
- 卡名：**技能 · 它自己选**
- 卡面描述：装上本领，它见活举牌。卡面画：伙伴举着一张发光小牌。
- 卡背口诀：**「装了技能牌，自己会安排」**

**影子引导方案**
- **影子档位切换：S2 → S1 提示词**。积木区不再有任何块，只有语音+浮动提示（「先放角色卡」「技能牌装进槽」）。前 4 课所学（角色卡/触发器/百宝箱）全部由孩子自己从卡包搭回——复习内建于新关。
- 作品「修桥小队长」：角色卡+触发器（自搭）+ 百宝箱（自搭）+ **技能槽×2（缺口1）** + **测试指令×2（缺口2、3）**。
- 本关卡包技能牌仅 2 张：画画/算数，全都要装（不做取舍）。
- 第一缺口一步必对：**近乎必对**（技能槽只吃技能牌，同槽互换磁吸）；测试指令需有效（含画画词或算式），无效指令伙伴温柔反问「你想让我做什么呀？」（可无限重试）。

**哇哦时刻（全课程核心高光）**
孩子说「画3只小猫」——**没人告诉它用画画，它自己举起画画牌**，然后画里真的有 3 只猫（可数）。老师带全班"整蛊测试"：故意说「画5朵云」「2+2等于几」，看它自己换牌。全场尖叫点。**界面刻意不提供"手动指定工具"的入口**——理念即关卡。

**三星通关验收**
- ★：2 张技能装上 + 完成 1 次画画或回答
- ★★：发 4 条标准测试指令（画3只小猫/画5朵云/3+4等于几/10-2），`EVT_TOOL_AUTO_PICK.correct ≥3/4`，且画画数量正确（模板计数检测）
- ★★★口诀测验：「技能牌，谁说了算？」答「它自己选」→点亮「技能」卡。

**低年级适配**
测试指令改为"按钮指令卡"（图+语音：🐱×3），不打字；画画结果为大颗粒贴纸拼贴风。

**时间分配**
过场 5′ / 创作（自搭复习+装技能）20′ / 测试（自主举牌实验，本课重心）12′ / 展示 6′ / 悬念收尾 2′。

### 第 6 课 · 关卡 6「暗号行动」

**知识点与教学目标**
- 概念：**触发器进阶**（语音暗号触发技能）；**技能槽容量有限 → 取舍策略**。
- 目标：设计触发条件；体验「喊暗号→技能执行」完整链路；学会根据目标配置技能组合。

**15 秒过场脚本**
- 0–5s：「夜。环带集市。卖艺的桥，还差一块。」画面：夜市灯一盏盏亮起。
- 5–10s：「伙伴想上台。可它紧张。给它一个暗号。听到暗号，它就开嗓。」画面：伙伴躲在幕布后探头。
- 10–15s：「槽只有三个。技能有四个。你决定，带哪个。」画面：四张牌摊开，三个槽，一张被月光照着。

**新积木图鉴卡：暗号触发器**
- 卡名：**触发器 · 喊暗号**
- 卡面描述：听到那句话，本领立刻开始。
- 卡背口诀：**「喊暗号，本领到」**

**影子引导方案**
- 作品「上台小明星」：角色卡+百宝箱（自搭）+ **技能槽×3（缺口1：4 张技能牌——唱歌/讲笑话/画画/算数——必须弃 1）** + **暗号触发器（缺口2：自由设暗号词，绑定唱歌或讲笑话）** + **集市问答×2（缺口3：用百宝箱答摊主问题）**。
- 影子：S1 提示词。缺口：3。
- 第一缺口一步必对：**否（策略型缺口，本无标准答案）**。装了画画没装唱歌→喊暗号没反应→孩子自己发现、自己换装（**试错学习重点关**）。被弃技能触发伙伴性格台词（傲娇猫：「哼，本来也不想唱。」捧场狗：「我把机会让给画画啦！」）。

**哇哦时刻**
全班关灯。每个孩子喊自己的暗号——教室里歌声、笑话声此起彼伏；伙伴**只听自己主人的暗号**，别人的暗号一律不理（个性化触发）。孩子第一次感到"这是我调教出来的、独一无二的它"。

**三星通关验收**
- ★：暗号触发成功 1 次（`EVT_TRIGGER_VOICE → EVT_TOOL_EXEC` 链路成立）
- ★★：4 条混合测试：2 条暗号+2 条常规（画/算），全部正确响应（链路×2 + `EVT_TOOL_AUTO_PICK`×2）
- ★★★口诀测验：「喊暗号，是为了？」答「让它开始本领」→点亮「暗号触发器」卡。

**低年级适配**
暗号从预设图标库选 8 个（星星/棒棒糖/火箭…），避免语音识别挫败；技能槽扩为 4 张全装（不做取舍），取舍作为高年级挑战任务。

**时间分配**
过场 5′ / 创作（含换装试错）20′ / 测试（暗号大合喊）10′ / 展示 8′ / 悬念收尾 2′。

### 第 7 课 · 关卡 7「晚会策划师」（展示+组合技）

**知识点与教学目标**
- 概念：**展示积木**（气泡/举牌/烟花）；**组合技：百宝箱×技能**（查资料→举牌报答案）。
- 目标：独立搭建完整「问答→查→答→秀」多积木链路。

**15 秒过场脚本**
- 0–5s：「今晚，环带晚会。全场伙伴，都要出节目。」画面：篝火升起，舞台空着。
- 5–10s：「你的伙伴，当策划师。客人问，它查，它答。」画面：三个 NPC 客人排队。
- 10–15s：「答得好，放烟花。让全场记住它。」画面：答案牌+烟花同框。

**新积木图鉴卡 ×2**
- 卡名：**展示 · 放烟花**｜卡面：答得好，天开花｜口诀：**「答得好，烟花冒」**
- 卡名：**组合技 · 查完举牌**｜卡面：先查百宝箱，再把答案举起来｜口诀：**「先查箱，再举牌」**

**影子引导方案**
- **影子档位：S1-lite 任务清单模式**——四行语音清单（①喂晚会资料 ②装举牌技能 ③绑烟花 ④自创一个环节），每完成一行打勾，但**积木位置、选型全部自由**（比 L5–L6 的提示词更放手，为 L8 空白做过渡）。
- 缺口：4。第一缺口一步必对：**否**（资料可喂错→客人答非所问→自行修正）。
- 卡包资源：资料×3（节目单/时间表/菜单）、技能×4（举答案牌/唱歌/画画/算数）、展示×2（烟花/彩带）。

**哇哦时刻**
链路跑通的一刻：NPC 问「烟花几点放？」→ 伙伴**自己**翻百宝箱（徽章亮）→ **自己**举起答案牌「八点整」→ **自己**放烟花。三步没有任何人工指挥。孩子喊「它全自己干的！」。彩蛋：烟花瞬间在全班屏幕局域网同步炸开。

**三星通关验收**
- ★：完整链路跑 1 次（事件序列检测：`EVT_RAG_HIT → EVT_TOOL_EXEC(答案牌) → EVT_SHOW(烟花)`）
- ★★：3 位 NPC 客人问题全答对 + 徽章亮 3 次 + 烟花 ≥1
- ★★★口诀测验：「它举牌前，先干了啥？」答「查百宝箱」→点亮「展示」「组合技」双卡。

**低年级适配**
NPC 问题全语音+图片；烟花积木一键式；任务清单逐行朗读，完成一行才亮下一行。

**时间分配**
过场 5′ / 创作 25′（本课创作量最大）/ 测试 7′ / 展示 6′ / 悬念收尾 2′。

### 第 8 课 · 关卡 8「星核拼合 · 毕业发布会」

**知识点与教学目标**
- 概念：三要素综合（角色卡+百宝箱+技能）完成完整智能伙伴；**轻碰剧本**（仅一枚可选彩蛋积木）。
- 目标：独立配置并通过发布运行；能向他人讲清作品每个部分。

**15 秒过场脚本**
- 0–5s：「八颗星核，集齐了。舱门，就要开了。」画面：星语号船头，星核槽位一一亮起。
- 5–10s：「最后一步。做一件大礼：你的伙伴，2.0 版。」画面：伙伴挺起胸，披风飘起。
- 10–15s：「带上它，去见真相。」画面：舱门缝隙透出光，音乐收住。

**新积木图鉴卡：剧本 · 如果就（隐藏彩蛋）**
- 卡名：**剧本 · 如果就**
- 卡面描述：答对时，放烟花。（装不装，都能毕业）
- 卡背口诀：**「如果这样，就那样」**
- 出现方式：藏在卡包最底层，点问号才展开。教师话术：「这是下学期第一课。想提前尝一口吗？」——前 8 课时对控制流的唯一触碰，点到为止。

**影子引导方案**
- **影子档位：S0 完全空白**。无影子、无清单、无提示词，只有图鉴卡可翻。
- 硬性配置线（自动检测）：≥1 角色卡、≥1 百宝箱（含 ≥2 资料）、≥2 技能、≥1 触发器。剧本积木可选。
- 发布会形式：20 人分 4 组互展（每组 5 人，人人演示）→ 每组推 1 名上台全班演示（5 人 ×3 分钟）。

**哇哦时刻**
全班通关瞬间同步播放**星核拼合全屏动画**→星语号舱门缓缓打开→里面是一个笼子→名牌「第二个伙伴」→灰雾原来也是星灵（悬念炸点）。此时预览区所有 6 款伙伴一齐安静下来，望向舱门——Agent 情感化收尾，为第 9 课（营救灰雾）蓄满情绪。

**三星通关验收**
- ★：作品配置达标（积木类型计数自动检测）+ 发布运行成功
- ★★：现场演示 3 问 3 答（语音记录判定：1 个性格问题/1 个知识问题/1 个技能问题，均正确响应）
- ★★★**口诀大闯关**：升级为前 7 课口诀连答 5 题，全对→已点亮知识卡集体进阶为"闪卡"（图鉴收集冲刺）。

**低年级适配**
配置线降级为：角色卡+百宝箱（1 资料）+技能 1；发布会可由"小老师"结对代讲，作品署双名。

**时间分配**
过场 5′ / 创作 20′ / 测试（组内互展互检）8′ / 展示（上台 5 人+星核动画）10′ / 悬念收尾 2′。

## 六、开发对接备注

1. **事件埋点清单**（三星检测依赖）：`EVT_TRIGGER_TAP / EVT_PERSONA_SWAP / EVT_RAG_FEED / EVT_BADGE_RAG_HIT / EVT_RAG_HIT_SPECIFIC / EVT_TOOL_EQUIP / EVT_TOOL_AUTO_PICK / EVT_TRIGGER_VOICE / EVT_TOOL_EXEC / EVT_SHOW_FIREWORK / EVT_QUIZ_PASS`。
2. **徽章动画**（RAG 命中）与**举牌动画**（工具自选）是两套核心反馈，需最高优先级打磨——分别是第 1 章与第 2 章的"概念可视化锚点"。
3. 伙伴性格台词需按 6 款动物 × 每关关键节点（唤醒/答非所问/恢复记忆/弃技能/望向笼子）准备语料，全部短句。
4. L1 的"10 分钟出作品"要求预置作品模板随关卡下发，孩子进入即见影子，零冷启动。
