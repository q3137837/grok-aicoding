## 一、项目定位与核心理念

面向小学 AI 编程教学场景的**图形化 Agent 创作平台**。与 Scratch/编程猫的本质差异：**孩子搭建的不是"程序"，而是一个"有性格、有知识、有技能的智能体"**——人设（Persona）、知识库（RAG）、技能（Tool Calling）全部积木化，底层完整对齐真实 Agent 架构，前端完成低龄化封装。

服务于教培机构的进校课程与自有机房课，实现「机构自持 API、学生数据独立隔离、家长零门槛参与」。

### 核心设计原则

1. **Agent 原生**：积木体系直接映射智能体三要素（人设/知识/技能），孩子学的是 AI 原生思维而非传统控制流
2. **低龄友好**：全程拖拽、无代码输入、视觉反馈默认（不依赖机房声音）、年级分级交互
3. **教学导向**：任务即关卡、关卡即知识点；**激励必须绑定掌握验证**，抽卡集齐 ≠ 点亮
4. **课堂抗造**：断网、API 失败、浏览器崩溃，课都上得下去——异常预案是一等功能，不是兜底
5. **轻量上手**：网页端开箱即用，10 分钟完成首个可运行 AI 作品（产品化硬 KPI）
6. **家校联动**：家长零下载零注册、零个人信息收集（家庭码绑定），微信群内完成传播

## 二、角色与权限架构

### 1. 老师账号（机构运营者 + 教学端）

- **BYOK API 主权**：机构绑定自有 API Key，支持**多 Key 分组池化**（见第八章），学生调用按组路由，token 消耗从机构账户计量扣减
- **用量看板**：今日/累计 token、调用次数、失败率、**分组池水位**；全量调用日志可追溯
- **班级管理**：课堂码进场、批量增删、一键重置
- **教学管理**：关卡任务发布、闪电点赞/投屏、画廊批改、暂停锁屏

### 2. 学生账号（创作端）

- **零 API 感知**：加入班级自动复用机构 API 配置
- **数据完全独立**：作品库、草稿、卡牌收藏仅本人与老师可见，跨学生跨班级隔离
- **极简接入**：学号 + 姓名 + 课堂码扫码即入
- **图形化创作**：全程拖拽，无任何代码输入

## 三、老师端：课堂教学控制台

### 1. 一键上课（3 次点击开课）

首页「上课」①（按课表推荐今日班级）→ 任务选择②（置顶"上节课进度推荐"）→ 大屏自动显示课堂码 + 二维码，学生扫码进入③。座位网格从灰变亮、迟到标黄——**点名被淘汰**。

### 2. 课堂控制流：心跳 + 智能呼叫

- **增量状态心跳**（替代缩略图快照上传）：学生端仅向老师端发送极小数据包——当前积木节点数、报错状态、活跃/闲置标志（字节级，机房弱网可承受）。老师需要看画面时再点开实时预览（按需拉取，不常驻上传）
- **智能呼叫（Smart Intervention）**：后台自动检测卡顿行为——同一积木停滞超 90 秒、AI 返回错误 ≥2 次、长时间无操作——自动将该学生格子高亮并**置顶为"待协助"**，老师不用盯 20 个小屏
- **求助队列**：学生主动求助自动附当前积木区状态，与智能呼叫合并为同一队列（按时长排序）
- **暂停锁屏**：一键全班锁成"抬头看老师"，再点恢复

### 3. 当堂闪电点赞（即时激励，新增）

小学生的激励窗口以分钟计，课后奖励衰减 70% 以上。老师平板常驻**闪电点赞按钮**：看到谁做出好东西，点学生格子 → 点「上大屏」→ 该学生屏幕投上教室大屏 + 全班端同步播放 10 秒庆祝（彩带 + Agent 撒花 + 该学生头像），徽章/能量**当场到账**。全流程 3 秒内完成，不打断课堂节奏。画廊批改与本课之星保留，作为课后的深度激励层。

### 4. 画廊式批改 + 语音评语 + 本课之星

下课后横向滚动批改 20 幅作品，停留即播 10 秒运行录屏；星级一次点按、长按麦克风语音评语（保留原声家长可听）；「本课之星」下节课进场开屏庆祝。

### 5. 课堂节奏

大屏常驻全班进度条（已提交金/创作中蓝/未开始灰）；任务倒计时最后 5 分钟橙色脉冲。

## 四、图形化 Agent 编辑核心（学生端）

### 1. Agent 原生积木体系（六类，重构）

**这是与 Scratch/编程猫拉开差异的核心**。积木直接映射智能体架构，孩子搭的是"一个 Agent"，不是"一段程序"：

| 积木类型 | 颜色 | 核心积木 | 映射的 Agent 概念 | 对应知识点 |
| --- | --- | --- | --- | --- |
| **角色卡** | 紫 | 身份选择（侦探/画家/故事大王）、性格贴纸、说话语气 | **Persona / System Prompt** | 提示词工程入门：AI 的回答由"角色"决定 |
| **知识百宝箱** | 蓝 | 拖入资料卡（文字/图片/班级资料）、开箱关箱 | **RAG / Context** | 知识增强：AI 不懂的专有知识可以"喂"给它 |
| **技能** | 橙 | 装备技能槽：画画、算数、识图、讲故事……可多选 | **Tool Calling / Function Calling** | 工具调用：AI 根据意图**自主选择**用哪个技能 |
| **触发器** | 绿 | 开始、听到关键词、看到图片 | Event / 意图识别入口 | 事件与输入 |
| **剧本** | 黄 | 如果…就…、重复、等待 | 对话流程编排 | 顺序/条件/循环（传统控制流保留为剧本逻辑） |
| **展示** | 粉 | 说话气泡、表情、播放成果 | 输出呈现 | 结果表达 |

**关键交互设计**：

- **角色卡是"起点积木"**：每关先给 Agent 选身份——同一个"讲个睡前故事"请求，侦探 Agent 和画家 Agent 的回答完全不同，孩子第一节课就能直观感受"人设改变 AI"——这就是最早的提示词工程认知
- **知识百宝箱可视化"喂知识"**：把资料卡拖进箱子，Agent 回答时胸口亮起"我用了百宝箱里的知识哦"徽章——让 RAG 从黑盒变成可感知的行为
- **技能自主选择是"哇哦时刻"**：给 Agent 装备"画画 + 算数"两个技能，说"帮我画 3 只小猫"→ Agent 自己举起"画画"技能牌开始画。**孩子观察 AI 为什么选这个技能**——这是对 Function Calling 最直觉的教学。运行日志以"Agent 的思考卡片"形式展示（我想了想，这个问题要用画画技能）
- 传统控制流（如果/重复）收纳进黄色"剧本"类——低年级前 8 课时甚至可以不碰剧本积木，纯靠 角色卡+知识+技能+触发器 就能做出"会聊天的智能伙伴"，逻辑控制随章节渐进引入

### 2. 任务关卡化：星空闯关地图

- "一章一岛"卡通地图，星球节点四态：灰锁 / 呼吸发光 / 三星完成 / 彩旗（班级通关排行）
- 关卡三段式：15 秒过场动画（Agent 朋友被困，编程营救）→ 影子引导 → 通关英雄胜利页
- 脚手架褪除：第 1 章全影子 → 第 3 章只给轮廓 → 第 5 章只给提示词
- **关卡主题即 Agent 概念**：第 1 章"给我的 Agent 起个身份"、第 2 章"喂它吃知识"、第 3 章"给它装备技能"……章节叙事直接教 Agent 思维
- AI 小精灵分级提示（抽屉金边 → 缺口影子 → 讲思路），每关限 3 次

### 3. 自由创作星球（新增）

星空地图之外常驻一颗**自由星球**：

- 无影子引导、无任务目标，全部已解锁积木开放
- 作品保存进"自由作品库"，可提交**班级创意广场**（老师审核后全班可见，同学可运行/点赞）
- 覆盖课后自主学习场景，是产品粘性与家校联动的地基——上完课孩子还有地方回去
- 自由作品同样计能量（提交 +10、被点赞 +1），被老师选入"精选广场"额外 +20

### 4. 编辑器交互与年级分级

- **低年级（1-2 年级）**：双栏布局（画布 + 底部超大积木托盘，触控目标 ≥60px），运行全屏弹出
- **高年级（4-6 年级）**：三栏布局
- 单积木文案 ≤6 字；卡口形状防语法错误
- **无声视觉模式（默认）**：机房通常无声音输出——所有反馈默认走视觉通道：积木点按朗读改为**字幕气泡 + 高亮**；小精灵纠错用手势表情 + 图标字幕；磁吸"咔哒"音效替换为星粒子迸发的强化视觉。老师端按机房条件一键开启声音（有耳机/音响的场地）

### 5. 哇哦时刻

- 磁吸果冻手感（40px 吸附 + 弹簧缩放 + 星粒子；声音为可选通道）
- 运行成功庆祝：积木波浪舞 → Agent 撒花 → 彩带 1.5 秒；首次完成"发射仪式"落班级银河墙
- Agent 角色化：6 款性格动物；拖入"百宝箱"积木它抱紧箱子、装备"画画"技能它戴贝雷帽——**对 Agent 积木的反应本身在强化概念认知**

### 6. 低龄容错清单

| # | 设计 | 说明 |
| --- | --- | --- |
| 1 | 拖拽放大投影 | 离手前放大 1.3 倍 + 落点阴影 |
| 2 | 长按锁拖 | 按住 0.5 秒才可拖，单击只展示朗读字幕 |
| 3 | 垃圾桶吃积木 | 馋嘴吞入 + 30 秒内吐回，替代文字确认弹窗 |
| 4 | 视觉朗读 | 点按积木字幕气泡显示内容（无声模式）/ 可选语音 |
| 5 | 撤销飞回动画 | 积木沿轨迹飞回原位 |
| 6 | 跟读式调试 | 逐块高亮 + 字幕展示积木内容 |

### 7. 运行机制（对学生透明）

积木拼接 → 编译为 Agent 配置（Persona + 知识引用 + 技能列表 + 流程）→ 服务端按组路由 API 池执行（削峰队列 + 计量）→ 流式回传。保存即版本快照。

## 五、小组协作：岗位专属面板（重构）

轮流制解决了低龄误操作问题，但"三人围观"会注意力涣散——V1.2 改为**三人各有专属面板、有事可做**的轻量并行：

**协作模式：1 名操作员 + 3 名岗位面板**

| 岗位 | 专属面板（学生自己屏幕上） | 做的事 |
| --- | --- | --- |
| **设定师** | 角色卡编辑面板 | 拖性格贴纸、选语气、试写 Agent 人设，实时改主画布 Agent 的角色 |
| **知识官** | 百宝箱管理面板 | 浏览/拖入资料卡、开箱关箱，管理 Agent 的知识库 |
| **测试员** | 测试对话面板 | 向 Agent 提问、给回答打分（👍/👎），记录"测试用例"反馈给操作员 |

- 三人成果**实时自动汇总到主 Agent 画布**（操作员屏幕 + 全组可见投影），任何岗位改动主画布对应积木区即时发光提示——孩子直观看到"我的工作进入了共同作品"
- 低年级仍可切回纯轮流制（老师端按班级设置）
- 分组：手动/随机；积分：小组基础分 + 岗位贡献分（按面板操作记录自动计算）
- API 额度按组管控，超限需老师审批

## 六、激励体系：能量 - 盲盒 - 集卡（掌握验证版）

### 1. 核心改造：图鉴点亮必须通过"掌握验证"

V1.1 的"抽到卡即点亮图鉴"是伪关联——抽卡和学会没有必然联系。V1.2 把**收藏**与**点亮**拆开：

- **抽到卡 = 获得卡面收藏**（可以放进收藏册、可以交换）
- **点亮卡 = 通过该卡对应的掌握验证**：
  - 知识卡：通过对应关卡**三星通关**（三星标准含"未用提示""一次运行成功"等掌握信号），或**口诀小测验**答对
  - 组合技卡：完成对应互动剧情的算法问答
- **图鉴完成度、阶梯奖励、班级荣誉墙全部按"点亮数"计算**，不按收藏数——**集齐 = 学会**，家长看到的图鉴 = 真实掌握成绩单
- 卡背口诀填空复习保留（每日 3 题，答对 +2 能量）——复习本身是点亮路径之一

### 2. 能量值（锚定"完成 + 迭代 + 掌握"）

| 行为 | 能量 |
| --- | --- |
| 提交作品 | +10 |
| 作品迭代改进 | +10 |
| 作品评优 / 精选广场 | +20 |
| 小组协作完成 | +15/人 |
| **知识点点亮（掌握验证通过）** | **+8** |
| 签到 | +1 |
| 获赞 | +1（日上限 3） |
| 每日口诀复习 | +2×3 |

家长互动为成就型（点亮班级荣誉墙、亲子共学徽章），不产出可消费货币。能量出口：盲盒、皮肤租用、集市找零、直购区。老师管控：每日上限、一键关闭随机（切换积分直购）。

### 3. 盲盒：许愿开盒（随机保留 + 合规护栏）

- 许愿卡 + 软保底（连续 3 次落空第 4 抽必出）；10 抽稀有保底并行
- 奖池：创作道具 55% / 集卡 40% / 权益 5%（AI 额度不在池内，全员统一配额）
- 概率家长端扫码可见并印于换卡海报；开盒记录留存 3 年备查
- 注意：盲盒产出的是**卡面收藏与装饰内容**，与图鉴点亮（掌握验证）解耦——想要点亮，去通关、去答题

### 4. 集卡「编程冒险家」

- 冒险图鉴四区域（顺序王国/循环森林/分支山谷/AI 学院），**按点亮进度点亮地块**（草地/天气特效/地标/夜空）
- 卡牌组合技「冒险搭档」：组合解锁隐藏剧情（剧情内算法问答推进）；剪影清单制造探索缺口
- 通关口诀歌：集齐点亮系列后连成完整口诀，可播放旋律版、录制全班合唱版

### 5. 冒险家集市

班级内以卡换卡 + 能量找零、语音留言、24 小时冷静期；周五集市日；微信群换卡海报（九宫格 + 缺卡 + 概率公示码）。

### 6. 阶梯奖励（按点亮数）

集齐点亮普通 → 称号 + 彩虹皮肤；+稀有 → 模板包 + 实体徽章；史诗 → 线下活动优先权 + 一对一指导；全套 → 电子证书 + 班级展示位。

## 七、家长端轻量化方案（微信 H5）

核心原则：零下载、零注册、**零个人信息收集**，全程微信内完成。

**绑定方式（重构）**：**4 位家庭码**——学生端"邀请爸爸妈妈"生成一次性 4 位数字码，孩子报给家长，家长在 H5 输入即完成绑定。不收集手机号、不注册账号，后续凭微信身份免登。码可随时在学生端重置。

**四个页面**：

1. **作品欣赏页**：孩子最新作品在线运行、打气/点赞（成就型）、生成海报转发
2. **成长周报页**：一张图三个数据 + **图鉴点亮进度**（= 真实掌握知识点清单），10 秒看完
3. **亲子共抽页**：每日 1 次免费同步开盒，卡背知识点讲解
4. **换卡海报页**：九宫格海报转发班级群，缺卡需求一键发布

**隐私边界**：家长仅见自己孩子数据；海报仅卡通昵称 + 卡面；不可编辑孩子作品。

## 八、课堂运行保障（新增章节：抗造是一等功能）

机房/进校 WiFi 是"灾难级"网络环境，以下机制全部进 P0：

### 1. 分组 API 池 + 服务端削峰

- 20 人同时点"运行"= 20 个并发流式请求打向单个 Key，必触发服务商 Rate Limit、吃满机房带宽
- **解法**：机构可绑多个 API Key（不同服务商/账号均可）组成**分组池**，按小组分配路由（4-5 组 × 各自 Key）；服务端设**削峰队列**——同组并发上限（如 3），超出的排队并以"Agent 正在排队思考"的等待动画呈现，不报错
- 单次请求失败自动重试 1 次 → 切组内备用 Key → 仍失败进入 AI 降级提示（见下）
- 老师端看板显示**各池水位**（当前并发/排队数/失败率），上课前一眼确认额度

### 2. 离线任务模式

- 老师上课前可对今日任务执行**"缓存任务包"**：关卡剧情、积木模板、示例素材全部本地化；AI 积木的返回预置**离线演示数据**（对常见输入预先生成的示例回答，界面标注"离线演示"角标）
- 断网时学生端自动切入离线模式：拼积木、看剧情、跑离线演示全部可用——**课不中断**；恢复联网后 AI 积木自动回到真实调用
- 离线模式下提交的作品标记"离线完成"，联网后同步

### 3. 进度永不丢失

- 编辑操作**先写本地存储**（浏览器 IndexedDB），再异步同步云端；断网期间所有操作持续落本地
- 浏览器崩溃/死机/误关：重进后自动检测本地未同步草稿，弹小精灵"我把你的作品找回来了"+ 一键恢复
- 版本快照双写（本地 + 云端），断线重连自动合并

### 4. AI 失败的儿童友好降级

- API 失败/排队超时：预览区小精灵出现——"AI 打瞌睡了，再试一次？"（视觉模式：表情 + 图标字幕），自动后台重试
- 全班性 API 故障：老师端大提醒（"当前 API 池异常，建议切换离线演示模式"），一键全班切离线
- 学生永远看不到红色报错堆栈——错误反馈永远是角色化的、带下一步建议的

## 九、版本迭代优先级

### P0（第一版：抗造地跑通一节课）

班级管理（课堂码）、关卡化任务中心（内置关卡模板 + 提交）、**Agent 原生编辑器**（角色卡/知识百宝箱/技能 + 磁吸手感 + 影子引导）、本地优先自动存档 + 崩溃恢复、一键上课 + 暂停锁屏、**心跳 + 智能呼叫 + 求助队列**、**分组 API 池 + 削峰队列**、**离线任务模式**、限额计费 + 用量看板、全班进度条、基础能量积分、**无声视觉模式**

### P1（第二版：教学体验与续费）

当堂闪电点赞 + 投屏、画廊批改 + 语音评语 + 本课之星、自定义任务、易错积木分析、星空闯关完整章节系统、Agent 角色化、自由创作星球 + 创意广场、岗位面板协作、盲盒 + 集卡 + 掌握验证图鉴、家长端 H5（家庭码绑定 + 四页面）
